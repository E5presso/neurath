# Phase 1: 제품·reference 권위

제품 authority와 reference를 canvas 작업 전에 고정합니다.

1. `references/product-authority.md` 순서로 화면 목적, 사람의 자세, surface와 state를 확인합니다.
2. Repository design source와 runtime-owned component availability를 live checkout에서
   읽습니다. Source가 없으면 `clean-slate`로 기록합니다.
3. Reference를 aesthetic evidence와 product/interaction evidence로 분리합니다.
4. Reference 이미지, source URL, 선택 기록과 사용하지 않을 부분을 canvas `References` 영역에
   원본 그대로 보존합니다.

Phase evidence는 `screen_authority`, `reference_inventory`,
`design_source_and_runtime_authority`입니다.
