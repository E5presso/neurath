# Reference evidence

Reference는 두 종류의 서로 다른 증거입니다.

## Aesthetic evidence

출시되지 않은 experimental UI concept도 aesthetic evidence가 될 수 있습니다. 실제 이미지에서
직접 관찰한 다음 축만 사용합니다.

- object와 text가 차지하는 면적
- crop, overlap, asymmetry와 edge tension
- type silhouette, line length와 숫자 처리
- color의 이름이 아니라 면적 분포와 역할
- imagery density, blur, texture와 depth 관계
- container, divider, border와 negative space

Concept image는 interaction, accessibility, responsiveness, production feasibility를 증명하지
않습니다. 관찰한 시각 관계를 자연어 mood tag로 대체하지 않습니다.

## Product and interaction evidence

실제 navigation, control behavior, state transition, tablet posture, one-hand mobile use와
accessibility를 가져오려면 배포된 제품, 공식 support/HIG 또는 직접 실행한 화면을 사용합니다.

## Canvas record

각 source는 원본 이미지, URL, captured_at, surface, 관찰, 가져올 시각 관계와 복사하지 않을
브랜드·copy·고유 layout을 함께 둡니다. 후보와 원본을 같은 canvas에서 나란히 유지합니다.
Text-only summary는 reference record가 아닙니다.
