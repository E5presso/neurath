# Help improve Neurath

[한국어](CONTRIBUTING.ko.md)

A Neurath change should make an agent's work easier to continue and its result easier to verify. Start with [contributor and agent onboarding](docs/en/contributing/index.md): it explains which instructions to read, how to establish the current execution state, and how to carry an authorized change through verification.

Work on the owned originals in `src/neurath/_assets`; installed skills and rules are generated installation content. Keep English and Korean documentation aligned at matching paths. The development guide covers the locked environment, repository checks, asset manifest, and self-installation workflow, including when each is needed.

Report what the evidence establishes: source checks, package execution, installation behavior, and actual host activation are separate results. Keep local execution records and private project information out of public changes. Publishing a commit, pull request, or release requires the relevant authorization.

If your goal is to use Neurath in another repository, begin with the [first walkthrough](docs/en/usage/start-here.md) and [installation guide](docs/en/usage/installation.md).
