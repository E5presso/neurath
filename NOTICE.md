# Development origins

Neurath began with harness components developed in the Amber project at commit
`4f1de1565f7fd992fc46114df8884e9f70069138`.

The current kit owns its runtime, host adapters, contracts, packaging, and regression tests.
It does not load or build from the original repository. Product-specific profiles,
application scaffolds, and framework dependencies are not installation assets.

Original extraction records and historical validation runs are retained in a local development
archive. They are not required to install, build, test, or use Neurath.
