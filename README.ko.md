# Neurath

[English](README.md)

Neurath는 요청, 실행, 위임, 완료에 걸친 에이전트 작업의 책임을 기록합니다. 작업 소유권과 순서가 있는 단계를 관리하고, 근거의 출처를 유지하며, 결과 보고와 결과 수락을 구분합니다.

이 저장소는 새로 작성한 **Neurath 0.3.0** 구현입니다. MCP 서버 이름은 `neurath`입니다.

## Neurath로 작업하기

연결된 에이전트에게 이루려는 결과와 성공 조건을 설명하세요. 예를 들면 다음과 같습니다.

> 보고된 문제를 고쳐 줘. 먼저 원인을 설명하고, 수정한 뒤 결과를 검증하고, 완료 처리 전에 근거를 보여 줘.

다른 에이전트에게 검토를 맡길 때는 다음과 같이 요청할 수 있습니다.

> 다른 에이전트에게 변경 내용을 독립적으로 검토해 달라고 요청해 줘. 원래 작업의 소유권은 여기에 유지하고, 결과를 수락하기 전에 검토 내용을 확인해 줘.

작업을 이어갈 때는 다음과 같이 요청할 수 있습니다.

> 내 미완료 작업과 현재 단계, 이미 기록된 근거를 보여 줘. 선택한 작업의 이전 이력을 버리지 말고 이어서 진행해 줘.

이 문장들은 작업 흐름의 예시입니다. 에이전트는 연결된 환경에서 실제 제공하는 연산을 사용하고 지원하지 않는 동작을 밝혀야 합니다. 작업 기록 자체가 외부 에이전트를 실행하거나 네이티브 동작의 실행을 입증하거나 사람의 승인을 제공하지는 않습니다.

## 결과 확인하기

유용한 결과에는 현재 소유자, 작업 상태, 완료한 단계, 남은 조건, 적용되는 근거가 드러납니다. 위임받은 에이전트의 보고와 소유자의 수락은 별도로 유지됩니다. 완료하려면 작업의 명시적인 조건을 충족해야 하며, 프로세스 종료나 성공한 통신 응답만으로는 부족합니다.

업그레이드를 확인할 때는 소스 체크아웃, 설치 배포본, 접근 가능한 프로토콜, 호스트가 실제로 불러온 연동을 구분하세요. 각각 별도의 관찰이 필요합니다.
