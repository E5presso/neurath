### 기억하고, 돌아보고, 이어갑니다.

- **작업을 기억합니다.** 대화가 끝나거나 Codex에서 Claude로 바뀌어도, 결정과 남은 일을 다음 세션으로 이어갑니다.
- **방향을 돌아봅니다.** 원래 목표를 다시 떠올려, 방법을 바꾸더라도 해야 할 일을 놓치지 않도록 돕습니다.
- **함께 완성합니다.** 에이전트끼리 발견을 공유하고 서로 검토하되, 각자의 수정 영역은 구분합니다.

Neurath는 Claude Code와 Codex 주위에서 조사, 협업, 세션 교체를 거쳐 개발 작업을 이어 가도록 돕는 하네스입니다. 사용하는 기술 스택에 관계없이 적용할 수 있습니다.

이름은 항해 중인 배를 바다 위에서 고쳐 나간다는 오토 노이라트의 비유에서 왔습니다. 여러 부분을 바꾸며 작업을 계속하더라도 도착할 목표를 잃지 않도록 돕습니다.

**[버그 수정 한 건을 처음부터 끝까지 따라가 보세요](docs/ko/usage/start-here.md).** 가상의 웹앱에서 저장한 필터가 새로고침 뒤 사라지는 상황으로 시작해, 필요한 개념을 그때그때 익힙니다. 내 Git 프로젝트에 적용하려면 [에이전트에게 설치 준비를 요청하세요](docs/ko/usage/installation.md).
