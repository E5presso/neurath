# Neurath

[English](README.md)

Neurath는 기존 Git 프로젝트에 설치해 쓰는 Claude Code·Codex 하네스입니다. 프로젝트 지침, 작업 추적, 검증 절차, 세션 간 기억을 연결해 에이전트가 요청을 구현하고 확인하는 과정을 돕습니다. 프로젝트의 작업 방식을 매번 설명하거나, 이전 세션에서 어디까지 진행했는지 다시 정리하는 수고를 줄일 수 있습니다.

핵심 전략은 에이전트가 작업 중 자신의 접근을 돌아보도록 돕는 것입니다. 원래 목표와 완료 조건을 주기적으로 환기해, 성과가 없는 방법은 바꾸면서도 요청받은 일은 이어가도록 돕습니다.

대상 프로젝트의 언어와 프레임워크, 문서와 테스트를 그대로 사용합니다. 원하는 결과를 말하면 에이전트가 그 작업에 맞는 절차를 따르고, 바뀐 동작과 확인한 결과를 설명합니다.

## 프로젝트에서 할 수 있는 일

- **프로젝트 기준에 맞춰 작업합니다.** 기존 지침을 따르고 연결된 문서와 검증 절차를 사용합니다. 버그 수정에서는 보고된 문제를 재현한 뒤, 해당 동작을 확인하는 테스트로 결과를 설명할 수 있습니다.
- **질문이 추가되어도 남은 일을 추적합니다.** 원래 요청을 확인 가능한 작업으로 나누고 의존 관계와 결과를 기록합니다. 진행 중 다른 질문을 해도 미완료 작업이 남아 있어 이어서 처리할 수 있습니다.
- **이전 세션의 맥락을 이어갑니다.** 관찰한 결정, 결과, 남은 일을 로컬 기억에 보관합니다. 다음 세션은 필요한 이력을 찾아 현재 소스와 비교한 뒤 작업을 계속할 수 있습니다. 사용량 한도로 한 제공자가 멈췄다면, 다른 제공자가 저장된 맥락을 가져오고 원본 실행의 중단을 확인한 뒤 남은 일을 승계할 수 있습니다.
- **여러 에이전트가 협업합니다.** 연결된 worktree의 에이전트끼리 발견한 내용을 공유하고, 각각의 작업 공간에서 독립적으로 일할 수 있습니다. 다른 공급자의 세션이 필요한 경우에는 요청한 모델과 권한으로 작업할 수 있는지 확인한 뒤 일을 맡깁니다. 일을 받는 제공자의 기존 설정을 유지하도록 요청할 수도 있습니다.
- **기존 개발 환경을 보존합니다.** 설치 과정에서 프로젝트 지침, 훅, 권한, 의존성, 가상 환경을 유지합니다. 하네스 실행 환경은 별도로 관리하며, 설치 이력을 이용해 업데이트하거나 이전 설치로 복원할 수 있습니다.

## 첫 요청

Claude Code나 Codex에서 프로젝트를 열고 다음과 같이 요청하세요.

> https://github.com/E5presso/neurath 의 Neurath를 이 프로젝트에 설치해 주세요. 기존 지침과 설정을 보존하고 프로젝트 문서와 검증 절차를 연결한 뒤, 현재 세션에서 활성화됐는지 확인해 주세요.

에이전트는 프로젝트를 살펴보고 설치할 구성을 준비한 뒤 적용 결과를 확인합니다. 호스트 로그인, 프로젝트 신뢰 설정, 새 세션 시작이 필요하면 구체적으로 안내합니다. 파일 설치와 진단 결과, 실제 호스트 활성화 여부는 각각 구분해 알려줍니다.

macOS와 Linux에서 사용할 수 있으며 Git과 Claude Code 또는 Codex가 필요합니다. 설치 과정에서 하네스용 Python 3.14를 준비합니다. 기본으로 두 호스트를 지원하도록 설치하며, 하나만 사용할 수도 있습니다. 호스트 선택과 업데이트·복원·제거 방법은 [설치와 관리](docs/ko/usage/installation.md)에서 확인하세요.

## 필요한 일을 말하세요

스킬 이름을 외울 필요는 없습니다. 원하는 결과, 제약 조건, 이미 확보한 근거를 함께 전달하세요.

> 이 테스트가 실패하는 이유를 재현하고 수정해 주세요. 어떤 동작이 바뀌었는지, 어떤 검사를 실행했는지 설명해 주세요.

> 이 변경에서 결함을 찾아주세요. 각 지적에 해당 코드와 실제로 문제가 발생할 조건을 포함해 주세요.

> 이전 세션에서 끝내지 못한 일을 이어서 해주세요. 당시 결정이 현재 소스에도 맞는지 먼저 확인해 주세요.

> 별도 에이전트에게 API 계약 검토를 맡기고, 당신은 자신의 worktree에서 승인된 이슈를 구현해 주세요.

기획, 명세 검토, UI 설계와 구현, 배포된 시스템의 QA, 의존성 관리, 승인된 변경 전달을 위한 절차도 제공합니다. [작업별 요청 방법](docs/ko/usage/skills.md)에서 구체적인 예를 볼 수 있습니다. 변경 게시나 권한 변경은 사용자의 지시를 따릅니다. Neurath 설치만으로 이러한 권한이 부여되지는 않습니다.
