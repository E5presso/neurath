**Neurath 설치와 유지 관리는 에이전트에게 요청하세요.** 에이전트가
[설치 실행 참조](../contributing/setup-reference.md)를 읽고 대상 프로젝트를 조사한 뒤
필요한 작업을 수행합니다. 이 문서는 사용자가 요청할 내용과 확인할 결과를 설명합니다.

## 프로젝트에 설치하기

> https://github.com/E5presso/neurath 의 Neurath를 이 프로젝트에 설치해주세요.
> 기존 지침·훅·권한·스킬·의존성을 보존하고 실제 문서와 검사 절차를 연결해주세요.
> 설치 결과를 확인하고 제가 직접 해야 할 호스트 설정이 있으면 알려주세요.

지원 환경은 macOS 또는 Linux, Git, Codex 또는 Claude Code입니다.
에이전트가 전제 조건을 확인하며, 간편 설치가 Python 3.14와 Neurath 전용 실행 환경을
준비합니다. 대상 프로젝트의 의존성과 개발 환경은 보존합니다.

최초 설치의 기본값은 generic 프로필과 두 호스트입니다. 한 호스트만 사용한다면 요청에
명시하세요. 설치 옵션과 기존 스킬 이름은 에이전트가 확인합니다. 이름 충돌로 접두어가
필요하면 Neurath 스킬에 별도 이름을 부여해 기존 스킬을 보존할 수 있습니다.
접두어는 이름 충돌을 해결하며, 다른 하네스와 실행 책임이 겹치는 문제는 별도 검토가
필요합니다. 에이전트는 해결되지 않은 충돌을 설명한 뒤 다음 작업을 진행합니다.

## 기존 프로젝트 연결하기

> 이 프로젝트의 기존 요구사항, 아키텍처 결정과 테스트를 사용해주세요.
> 관련 문서와 검사 방법을 찾아 연결하고, 기준이 불분명한 부분만 질문해주세요.

에이전트가 확인한 내용을 프로젝트 설정에 기록하므로 사용자가 설정 파일을 편집할 필요는
없습니다. 업데이트는 사용자가 수정한 연결 정보를 보존합니다.
검사를 연결하지 못했다면 미검증 상태로 남기며, 설치 과정에서 검사 방법을 임의로 정하지 않습니다.

## 결과 확인하기

에이전트에게 다음 결과를 구분해 보고하도록 요청하세요.

| 결과 | 확인하는 내용 |
| --- | --- |
| 설치와 로컬 진단 | 관리 파일 배치, 배포본 무결성과 훅 프로토콜 검사 |
| 프로젝트 검증 | 실제 프로젝트 검사를 설정된 성공 조건에 따라 실행했는지 |
| 호스트 활성화 | 실제 Codex 또는 Claude Code 세션에서 설치된 훅과 도구가 동작하는지 |

설치 도구가 사용자를 대신해 로그인하거나 호스트 신뢰를 승인할 수는 없습니다.
에이전트의 설명에 따라 필요한 인증과 신뢰 결정을 호스트에서 직접 진행하세요.
설치한 연동을 불러오기 위해 새 세션이 필요할 수 있습니다.
로컬 진단 통과만으로 호스트 활성화를 확인한 것은 아닙니다.

## 업데이트·제거·복구하기

| 하려는 일 | 에이전트에게 요청할 내용 |
| --- | --- |
| 변경 미리 확인 | “설치로 바뀔 내용을 조사하고 적용 전에 요약해주세요.” |
| 현재 프로젝트 업데이트 | “이 프로젝트의 Neurath를 업데이트하고 기존 수정 사항을 보존한 뒤 결과를 확인해주세요.” |
| 다른 프로젝트에 설치 | “이 대상 프로젝트에 Neurath를 설치하고 해당 프로젝트의 문서와 검사를 연결해주세요.” |
| Neurath 제거 | “프로젝트 파일과 수정 사항을 보존하면서 Neurath가 관리하는 연동을 제거해주세요.” |
| 설치 변경 되돌리기 | “설치 이력을 확인하고 이전 설치 상태로 복구해주세요.” |
| 중단된 설치 복구 | “중단된 설치를 조사하고 기존 내용을 버리지 않으면서 복구해주세요.” |

업데이트는 선택한 프로젝트에 적용하며, 다른 프로젝트의 실행 환경은 유지합니다.
이전 실행 환경은 복원에 사용합니다. 에이전트는 복구 전에 설치 이력과 충돌을 확인합니다.
관리 파일이 수정됐다면 업데이트·제거가 중단될 수 있고, 도구 환경이 불완전하면 설치가
중단될 수 있습니다. 내용을 강제로 덮어쓰지 않고 원인을 진단해야 합니다.
제거 후에도 빈 디렉터리와 변경 이력은 남을 수 있습니다.

설치 계획과 복구 기록에는 프로젝트의 원래 설정이 포함될 수 있으므로 로컬에 보관합니다.
구현과 명령에 관한 상세 내용은 에이전트가
[설치 실행 참조](../contributing/setup-reference.md)와
[설치 개발 안내](../contributing/installation.md)에서 확인합니다.
