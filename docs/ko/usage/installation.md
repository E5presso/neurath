# 설치·업데이트·복원하기

[English](../../en/usage/installation.md)

작업할 Git 프로젝트에 Neurath를 설치해 달라고 요청하세요. 에이전트가 기존 구성을 살펴보고 프로젝트 설정을 보존하면서 실제로 쓰는 문서와 검사 방법을 연결합니다.

> 여기에 Claude Code와 Codex용 Neurath를 설치해 줘. 기존 지침과 훅은 유지하고 이 프로젝트의 실제 검사를 사용해 줘. 사용할 준비가 되면 알려 줘.

## 첫 세션 준비하기

macOS 또는 Linux, Git, Claude Code 또는 Codex가 필요합니다. Python 3.14를 사용하며 빠른 설치 과정에서 준비할 수 있습니다. 처음에는 generic 프로필과 두 호스트를 기본으로 설치합니다. 한 호스트만 지정할 수도 있습니다.

에이전트가 통합을 준비하고 실행할 수 있는 검사를 수행합니다. 이후 로그인, 호스트의 신뢰 확인, 새 세션 시작, 도구 목록 새로고침이 필요할 수 있습니다. 결과에는 “Codex용 파일 설치 완료. 새 세션을 시작하면 통합을 확인할 수 있음”처럼 남은 조작이 드러납니다.

프로젝트에 다른 하네스나 이름이 비슷한 스킬이 있다면 설치 전에 겹치는 부분을 확인해 달라고 요청하세요. 스킬 접두사로 이름 충돌을 해결할 수 있습니다. 같은 훅이나 상태를 다루는 경우에는 어느 하네스가 맡는지도 정리해야 합니다.

## 기존 프로젝트 환경 유지하기

기존 지침, 훅, 권한, 사용자가 수정한 프로젝트 연결 설정, 프로젝트 의존성, 프로젝트 가상환경을 보존합니다. Neurath는 프로젝트와 분리된 실행 환경을 사용합니다. 한 프로젝트를 업데이트해도 다른 프로젝트는 기존 런타임을 사용하며, 이전 런타임으로 복원할 수 있습니다.

관리 파일을 수동으로 수정했다면 에이전트가 충돌을 보여 줍니다. 설치 계획과 백업에는 비공개 설정이 들어갈 수 있으므로 로컬에 보관합니다.

설정 과정에서는 실제 문서와 검사 방법을 연결합니다. 필요한 문서나 검사가 없으면 빠진 항목과 사용자가 정할 내용을 설명합니다. 자세한 예시는 [프로젝트에 맞게 연결하기](profiles.md)를 참고하세요.

## 업데이트 시점 선택하기

> 공식 안정 버전 업데이트가 있는지 확인하고 변경을 준비해 줘. 적용하기 전에 어떤 영향을 주는지 설명해 줘.

활성 작업 중에는 공식 안정 릴리스를 하루에 최대 한 번 확인합니다. 사용자가 다시 요청하면 추가로 확인할 수 있습니다. 안내에는 설치된 버전, 제안하는 버전, 주요 변경과 공식 링크가 포함됩니다. 별도 세션을 시작하거나 업데이트를 자동 적용하지는 않습니다.

에이전트가 제안할 업데이트를 준비한 뒤 선택을 받습니다. 명시적인 동의는 준비된 해당 제안에 적용됩니다. 응답하지 않으면 현재 설치를 유지합니다. 거절하거나 미룬 버전은 사용자가 다시 진행하기 전까지 보류합니다. 선택은 다음 세션에도 이어지며, 업데이트 후에도 보고와 기여 동의가 유지됩니다.

릴리스 확인에 실패해도 원래 작업은 계속합니다. 이전 업데이트가 중단됐다면 설치 상태를 점검하고 복구를 준비한 다음 다시 적용하도록 요청하세요.

업데이트로 파일이 바뀌어도 이미 실행 중인 도구 연결은 이전 버전을 계속 사용할 수 있습니다. 새 도구나 동작이 보이지 않으면 해당 MCP 연결을 다시 연결하고 활성 버전을 확인해 달라고 요청하세요. 파일 업데이트 결과와 현재 연결이 새 버전을 사용하는지는 따로 확인합니다.

다음처럼 요청할 수도 있습니다.

> 지금 작업을 저장하고, 필요하면 앱을 재시작한 뒤 같은 작업을 이어가 줘. 내가 머신을 직접 조작하지 않아도 되도록 준비해 줘.

호스트가 예약 실행과 앱 밖의 독립적인 재시작 수단을 제공하면, 에이전트가 둘을 준비한 뒤 앱을 종료할 수 있습니다. Neurath는 태스크 이력과 작업 소유권을 보존하고, 복귀 후 새 연결을 확인해 미완료 작업을 이어갑니다. 에이전트는 재시작 수단이 실제로 실행되는지 확인하고 다른 활성 작업을 보호하며, 목적을 달성한 재개 예약은 중지합니다. 앱 재시작은 호스트가 수행하는 작업이므로, 무인 실행 가능 여부는 해당 호스트가 제공하는 기능에 따릅니다.

## 이전 설치로 복원하거나 제거하기

> 이 프로젝트의 Neurath를 이전 설치로 복원해 줘. 내가 수정한 내용은 보존하고 복원한 통합을 확인해 줘.

업데이트 미리보기, 다른 프로젝트에 설치, 중단된 설치 복구, 관리되는 통합 제거도 요청할 수 있습니다. 에이전트가 설치 이력을 살펴 사용자 수정을 보존하면서 복원할 수 있는 범위를 확인합니다.

제거 후에도 빈 디렉터리, 설치 이력, 사용자가 수정한 프로젝트 연결 설정은 남을 수 있습니다. 결과에서 제거한 항목과 남겨 둔 항목을 확인할 수 있습니다.
