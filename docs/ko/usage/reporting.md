# 하네스 결함과 개선점 보고

[English](../../en/usage/reporting.md) · **한국어**

최초 설치 시 에이전트가 Neurath 공통 하네스의 결함·개선점을
[Neurath 공개 이슈](https://github.com/E5presso/neurath/issues)로 보고해도 되는지 묻습니다.
답하지 않으면 보고하지 않습니다. 명시한 선택은 현재 로컬 Git 프로젝트와 그 worktree에서
공유하며 업데이트 후에도 유지합니다. 새로 복제한 저장소는 별도로 동의를 받아야 합니다.

> 이 프로젝트에서 Neurath 공통 하네스의 결함·개선점 자동 보고를 켜주세요.

> 이 프로젝트의 Neurath 자동 보고를 꺼주세요.

에이전트가 선택을 저장하고 새 보고를 보내기 전에 다시 확인합니다. 꺼도 이미 공개한 이슈는
삭제되지 않습니다. 기존 인증과 호스트 실행 정책은 그대로 적용합니다.
보고할 수 없으면 초안을 로컬에 보존하고 원래 작업을 계속합니다.

동의한 상태에서 공통 하네스의 결함·개선점을 발견하면 로컬 수정과 함께 이슈를 보고합니다.
공통 보고 템플릿에는 Neurath 구성 요소, 기대 동작, 실제 동작, 일반화한 재현 절차와
개선안을 담습니다. 프로젝트 코드·전용 스킬과 규칙·업무 요구사항·이름·경로·원격 주소·
데이터·로그·대화·자격 증명·첨부는 포함하지 않습니다.
에이전트는 자동 검사뿐 아니라 내용의 의미도 검토합니다. 프로젝트 정보 없이 설명하거나
재현할 수 없다면 보고를 보류합니다.

프로젝트에서 발전한 기능은 별도의 개선 기여 제안으로 일반화할 수 있습니다.
에이전트가 공개할 정확한 제목·본문·대상 저장소를 먼저 보여 주고 해당 제안의 게시 동의를
받습니다. 자동 보고 동의로 이 절차를 대신하지 않으며 제안 내용이 바뀌면 다시 동의를 받습니다.
이슈 제안 동의는 프로젝트 코드 공개나 권리 이전 동의가 아닙니다.

현재 로컬 프로젝트에서 같은 초안을 다시 제출해도 이슈를 중복 생성하지 않습니다.
전송 결과가 불확실하면 자동 재시도하지 않고 확인할 수 있도록 보존합니다.
이슈 생성과 원격 내용 확인이 끝나면 에이전트가 이슈 링크를 알려 줍니다.
