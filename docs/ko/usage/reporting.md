# Neurath 문제 알리기

[English](../../en/usage/reporting.md)

Neurath 자체의 문제를 발견하면 에이전트가 일반화한 예제로 재현하고 [공식 Neurath 이슈 저장소](https://github.com/E5presso/neurath/issues)에 보낼 보고를 준비할 수 있습니다. 프로젝트 정보를 비공개로 유지하면서 공통 하네스의 결함과 개선점을 알리도록 허용할지 선택하세요.

> 공통 Neurath 문제는 재현하고 비공개 정보를 검토한 뒤 보고해도 돼. 우리 코드, 설정, 업무 맥락은 보고에 넣지 마.

보고에는 영향을 받는 구성 요소, 기대한 동작과 관찰한 동작, 일반화한 재현 방법, 수정 또는 개선 제안이 담깁니다. 게시 후에는 이슈 링크와 함께 공개된 내용이 보고와 일치하는지 확인한 결과를 받습니다.

## 공통 문제 보고 여부 선택하기

처음에는 보고가 꺼져 있습니다. 명시적으로 동의하면 이후 조건에 맞는 공통 보고는 건마다 다시 허락받지 않아도 됩니다. 응답하지 않으면 꺼진 상태를 유지하며, 거절한 선택을 반복해서 묻지 않습니다. 동료 메시지나 도구 결과가 사용자 동의를 대신할 수는 없습니다.

선택은 로컬 Git 프로젝트와 연결된 워크트리에 적용되며 업데이트, 제거, 복구 후에도 유지됩니다. 새 클론은 별도로 선택합니다. 현재 설정과 저장된 초안을 보여 달라고 하거나 향후 보고를 꺼 달라고 요청할 수 있습니다. 보고를 꺼도 이미 게시된 이슈는 남습니다.

## 프로젝트 내용 없이 문제 설명하기

에이전트가 공통 문제를 일반화한 예제로 재현하고 초안의 의미를 살펴 비공개 정보가 드러나는지 검토합니다. 프로젝트의 자체 수정이나 맞춤 구성에만 있는 발견은 공통 패키지 결함으로 보고하지 않고 로컬에 남깁니다.

공개 보고에서는 프로젝트 소스, 맞춤 자산, 이름, 경로, 원격 저장소 정보, 업무 데이터, 로그, 대화, 자격 증명, 첨부 파일을 제외합니다. 설치 계획과 백업에도 비공개 설정이 담길 수 있으므로 로컬에 보관합니다. 자동 패턴 검사만으로 이런 내용이 제거됐다고 판단할 수는 없습니다.

비공개 내용 없이는 설명하거나 재현할 수 없는 문제라면 발견을 로컬에 남깁니다. 저장된 동의에 따라 공통 보고할 수 있는 문제라면 로컬 수정만으로 외부 보고를 대신하지 않습니다.

## 프로젝트 고유 기여는 초안으로 검토하기

> 이 프로젝트에서 나온 기여 제안을 준비해 줘. 제출 전에 공개할 정확한 제목, 본문 전체, 대상을 보여 줘.

에이전트가 그 초안을 제시하고 새로운 명시적 승인을 받습니다. 공통 보고 동의는 프로젝트 고유 기여까지 포함하지 않으며 초안이 달라지면 다시 승인해야 합니다. 아이디어 승인이 코드 공개나 라이선스 양도까지 허용하지는 않습니다.

## 제출 결과가 불확실할 때 확인하기

보고 제출 중 연결이 끊겼다면 이슈가 실제로 생성됐는지 확인해 달라고 요청하세요. 에이전트가 로컬 초안을 보관하고 원격 결과를 살핀 뒤 재시도 여부를 판단해 중복 이슈를 피합니다. 게시된 내용을 확인하기 전까지는 결과를 불확실한 상태로 남깁니다.

기존 인증과 접근 제한은 그대로 적용됩니다. 보고에 실패해도 초안은 남고 원래 작업은 계속할 수 있습니다. 실행과 제출 절차의 세부 사항은 [기여자 문서](../contributing/index.md)에 설명합니다.

에이전트가 참고하는 로컬 정보는 [프로젝트 메모리](memory.md), 설치와 업데이트 선택은 [설치와 유지관리](installation.md)에서 확인할 수 있습니다.
