# 프로젝트에서 Neurath 사용하기

코딩 에이전트에게 맡긴 변경을 끝까지 마치려면, 무엇을 해결해야 하는지 유지하고 관련 작업을 조율하며 대화가 바뀐 뒤에도 필요한 기록을 되찾을 수 있어야 합니다. Neurath는 에이전트의 이런 작업을 돕습니다.

처음이라면 [요청부터 다음 대화에서의 재개까지](start-here.md)를 읽으세요. 사용자가 개발하는 가상의 웹앱에서 저장한 필터가 브라우저 새로고침 뒤 사라지는 문제를 따라갑니다. 필터는 예시 웹앱의 기능이며, Neurath는 필터 화면이 아니라 에이전트의 작업을 지원합니다.

## 실제 프로젝트에 적용하기

1. [저장소에 설치하기](installation.md): 에이전트에게 설치를 맡기고, 선택한 코딩 호스트가 실제로 Neurath를 사용하는지 확인합니다.
2. [프로젝트 기준 연결하기](profiles.md): 이 저장소에서 올바른 작업을 판단하는 기존 문서와 검사를 연결합니다.
3. [필요한 작업 요청하기](skills.md): 조사, 구현, 검토, 인계를 자연어로 요청합니다.
