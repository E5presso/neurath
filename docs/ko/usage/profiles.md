# 기존 프로젝트 문서와 검사 방식 사용하기

[English](../../en/usage/profiles.md)

에이전트가 어떤 문서로 프로젝트를 이해하고 어떤 검사로 변경을 확인할지 알 수 있도록 연결해 주세요. 이미 있는 자료를 살펴보고 용도에 맞게 사용하도록 요청하면 됩니다.

> 이 프로젝트의 기존 구조 문서와 검사 방법을 사용해 줘. 우리 용어와 작업 규칙을 유지하고 저장소에서 확인할 수 없는 결정만 물어봐 줘.

프로젝트 연결 설정은 에이전트가 관리합니다. 현재 프로필은 generic 하나이며, 언어·프레임워크·도구·작업 규칙은 프로젝트 지침을 따릅니다.

## 작업을 설명하는 문서 연결하기

프로젝트에 구조 결정 문서와 기여 안내가 있다면 구현과 검토에 활용하도록 요청하세요. 에이전트가 각 용도에 맞는 문서를 찾고 빠진 역할을 알려 줍니다. 적절한 문서가 없다면 그 공백을 남겨 두므로 필요한 정보를 사용자가 결정할 수 있습니다.

프로젝트 용어집과 작성 언어도 유지합니다. 기존 브랜치·커밋·이슈 규칙을 따르기 때문에 설치할 때 같은 규칙을 다시 정의할 필요가 없습니다.

## 결과를 판단할 검사 연결하기

> 이 부분을 확인할 때 쓰는 검사를 찾아 연결해 줘. 검사 범위와 실제로 실행할 수 있었는지도 알려 줘.

에이전트가 실제 검사 방법, 실행 위치, 프로젝트의 성공 조건을 확인합니다. 결과에서 무엇을 검사했고 통과했는지 알 수 있습니다. 검사가 없거나 실행할 수 없거나 제한된 경우에는 그 이유와 현재 작업에 미치는 영향을 확인할 수 있습니다.

기존 검사가 두 개라면 이번 작업에 어느 검사를 기준으로 삼을지처럼, 부족한 결정만 알려 주면 됩니다. Neurath 설정 파일을 직접 편집할 필요는 없습니다.

## 프로젝트 변화에 맞춰 연결 갱신하기

문서가 이동하거나 프로젝트의 검사 방법이 바뀌면 연결을 갱신해 달라고 요청하세요. 사용자가 수정한 연결 설정은 업데이트나 제거 후에도 사용자 소유로 남습니다. 설치 과정에서 기존 지침, 권한, 의존성, 프로젝트 환경도 보존합니다.

외부 서비스를 사용하거나 보호할 경로가 있다면 의도한 자원과 접근 범위를 알려 주세요. 에이전트가 실제 구성을 확인합니다. Neurath 설치만으로 모든 외부 서비스가 자동 보호되지는 않습니다. 문서 역할, 검사 설정, 커넥터 연결, 메타데이터 규칙, 하네스 자원의 기본 보호 범위는 [기여자 문서](../contributing/index.md)에 설명합니다.

이어서 [작업을 요청](index.md)하거나, 설정 변경 중 복구가 필요하면 [설치와 유지관리](installation.md)를 참고하세요. [용어 안내](../terminology.md)는 Neurath의 기록 이름을 설명하며 프로젝트의 도메인 용어를 대체하지 않습니다.
