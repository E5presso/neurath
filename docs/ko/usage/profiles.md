`generic`이 유일한 프로필입니다. 언어·프레임워크·모노레포 구조를 하네스가 정하지 않습니다.
기존 프로젝트 지침과 `.neurath/project.json`이 문서, 검증 명령, 선택적 보호 대상과
이슈·커밋 등의 메타데이터 관례를 결정합니다. 설정 예제와 명령은 [설치 안내](installation.md)에 있습니다.

31개 스킬은 대상 저장소와 현재 사용자 요청에 맞춰 실행합니다. 하려는 일과 그 작업에
필요한 근거·승인이 모두 맞는 스킬을 선택합니다. 예를 들어 구현은 승인된 이슈에서,
오류 조사는 재현할 수 있는 증상에서 시작합니다. [사용 안내](index.md)와
[스킬 목록](skills.md)에서 출발점을 고를 수 있습니다.

빈 문서 슬롯을 다른 프로젝트 문서로 채우거나, 검증 도구를 임의 설치하거나,
설정하지 않은 검증을 성공으로 처리하지 않습니다. 특정 외부 연동 도구는 기본 보호 대상이
아닙니다. 키트의 상태·규칙·실행 자산과 사용자가 명시한 경로·연동 도구만 보호합니다.

대상 프로젝트의 코드 변경에는 해당 프로젝트가 연결한 검증을 사용합니다. Neurath 자체
개발에 필요한 검사는 [기여자 안내](../contributing/index.md)에 정리했습니다.
제품별 전용 프로필은 제공하지 않으며 다른 제품의 상태를 이어받지 않습니다.
