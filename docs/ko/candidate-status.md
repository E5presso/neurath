# 로컬 후보 검증 기록

[문서 안내](index.md) · [English](../en/candidate-status.md)

이 기록은 2026-10-08 기준 로컬 0.3.0 후보의 상태를 설명합니다. 공개 릴리스, 푸시, 배포를 보고하는 문서가 아닙니다.

| 영역 | 관찰한 결과 |
| --- | --- |
| 자동 테스트 | 테스트 94개 통과. 필수 검증 진입점이 `NEURATH_CHECK_OK`를 출력함. |
| 설치 배포본 | 로컬 버전 0.3.0. 휠 SHA-256 `7656c4c6eb814f26dc7e3550725c1dc0e5ccfb0c82a1541c8f14d481ab1c35ca`. 런타임 `installed_version`도 0.3.0으로 확인됨. |
| 데이터 보존 | 데이터베이스 10개, 테이블 212개, 행 147,638개를 마이그레이션하고 검증. 원래 런타임 데이터베이스의 바이트는 변경되지 않음. |
| 미완료 작업 | 원래 소유권을 유지한 대기 작업 30개 보존. 소유 세션 21개는 `legacy-unknown`으로 표시. |
| 워크트리 정리 | 추가 워크트리 47개를 복구 가능한 보관본 검증 후 제거. |
| Codex 네이티브 활성화 | 사용자가 훅 신뢰를 승인함. 새로운 실제 Codex 세션에서 훅 활성·우회 비활성 상태로 `session_get`과 `task_list` 호출 성공. 네이티브 결과에서 `neurath` 0.3.0과 보존된 대기 작업 정확히 30개 확인. |
| Codex 세션 종료 | `SessionEnd` 제한 시간은 3초이며 실제 실행에서 제한 시간 보정 경고가 발생하지 않음. |
| 네이티브 변경·검사 생명주기 | 실제 Codex가 같은 검증 작업을 재개함. 실행기가 네이티브 실행 전 관찰을 거쳐 저장된 인자 목록을 실행하고 하위 프로세스 종료 코드 0과 테스트 94개 통과를 기록하여 성공 근거를 저장함. 조건을 충족하고 작업을 리비전 3에서 완료함. |
| 작성 임대 해제 | 검증 작업의 작성 임대를 해제함. `active: false`, 세대 1, 리비전 1. |
| Claude 네이티브 활성화 | 실제 Claude 세션에서 최종 설치 휠에 대한 `session_get` 호출 성공. 앞선 네이티브 실행에서도 `session_get`과 `task_list`가 성공했고 보존된 대기 작업 30개를 반환함. |

`legacy-unknown`은 세션 종료를 의미하지 않습니다. 작업 인수에는 여전히 명시적인 네이티브 사용자 출처와 이전 소유자의 확인된 종료 상태가 필요합니다. 마이그레이션은 이전 보고, 점유, 승인을 현재 권한으로 승격하지 않았습니다.

이 관찰은 Codex 활성화, 실제 설정 검사와 작업 완료 생명주기, 작성 임대 해제, 최종 휠에 대한 읽기 전용 호출을 통한 Claude 활성화를 입증합니다. Claude의 변경 생명주기를 입증하지는 않습니다. 보존된 작업 수는 축약된 모델 요약이 아니라 원래 구조화된 이벤트 로그에서 확인했습니다.

같은 검증 작업을 재개할 때 이전 실패 근거는 변경하지 않고 유지했습니다. 기존 사용자 작업은 수정하지 않았습니다. 새 성공 근거는 호스트의 도구 출력 표시 방식과 독립적으로 실행기가 관찰한 실제 하위 프로세스 결과를 기록합니다.

설치 흐름에는 [훅 신뢰 절차](../../CONTRIBUTING.ko.md#변경된-codex-훅-신뢰)를 유지하세요. 이후 훅 정의를 변경하면 사용자의 재검토가 필요할 수 있습니다. 새로운 호스트나 생명주기에 관한 주장에는 여전히 해당 관찰이 필요합니다.

최종 파일의 서식·import 정렬·타입 표기를 정리한 뒤 필수 검사를 다시 통과했고, 두 실제 호스트에서 위 최종 휠 해시를 읽어 확인했습니다. 전체 작업 생명주기의 원래 실행 근거는 별도로 보존했습니다.
