# 코어 설계 원칙

[English](../../en/contributing/design-principles.md) · [코어 계약](core-v2-spec.md)

하나의 Task aggregate를 진행 상태의 기준으로 둔다. 스킬 phase 순서와 미완료 Task의 Stop 차단을 유지한다. 목표 문장 비교 대신 명시적인 ID를 쓴다. 실패한 시도는 복구할 이력이며 사용자 목표의 취소가 아니다. 읽기와 차단 보고에는 쓰기 소유권이 필요 없다.

실행자 신원·자원 소유권·실행 방식 선택을 구분한다. worktree 격리가 세션이나 provider를 선택하지 않는다. 원문과 정확한 인용 구간으로 출처를 확인한다. 해시나 동료 보고가 사람의 동의를 증명하지 않는다. 호스트 권한을 유지한다. 코어는 호스트 보안 경계 안의 협업 수단이며 운영체제 sandbox가 아니다.
