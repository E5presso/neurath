# 설치와 코어 전환

[English](../../en/contributing/installation-design.md) · [코어 계약](core-v2-spec.md)

설치기는 관리 파일의 정확한 변경을 계획하고 쓰기 전에 오래된 계획인지 확인하며 journal로 롤백·복구한다. 사용자 지침·훅·권한·프로젝트 파일·스킬 추가 파일을 보존한다. 읽기 전용 설치 계획은 canonical 설치 metadata를 이관하지 않는다.

v1 전환 계획에는 보존할 미완료 Task와 소유권을 표시한다. 최종 적용은 기존 프로젝트 writer가 종료된 상태를 요구하고, 이관·파일 전환 동안 원본 SQLite 쓰기 잠금을 유지하며 원본 DB를 보존한다. 미완료 Task는 ID·목표·의존성을 대기 상태로 유지한다. 과거 보고는 새 검증이 되지 않는다. 완료된 전환 이력은 두 번째 실시간 진행 원장이 아니다. 설치가 중단되면 가져온 의무를 유지하고 설치 journal로 관리 파일을 복구한다.
