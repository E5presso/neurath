# Consent-based upstream reports

[한국어](../../ko/contributing/reporting-reference.md) · [Core contract](core-v2-spec.md)

`report status` reads the saved choice. A missing answer leaves automatic reporting disabled. Native `report prepare` accepts a bounded common-harness report after privacy review; `report submit` publishes that exact draft and reads back the result. Uncertain delivery must be reconciled rather than sent again. Project-specific contribution drafts require separate explicit approval.

The hook only supplies a local reminder; it never publishes a report. Decision commands need an interpreted approval tied to an actual input quote and exact native command target. A `--user-confirmed` argument cannot establish input provenance by itself. Existing consent and report history survive installation updates.
