# Use Neurath in your project

You have a coding agent and a change to finish. Neurath helps that agent keep the requested outcome in view, coordinate related work, and recover useful records when the conversation changes.

Start with [one investigation from request to return visit](start-here.md). It follows a hypothetical web application you are developing: a saved filter disappears after a browser refresh. The filter belongs to that example application; Neurath provides the agent's working support, not the filter interface.

## Put it to work

1. [Install in your repository](installation.md): ask the agent to prepare the project and verify that your chosen coding host is actually using Neurath.
2. [Connect your project conventions](profiles.md): give the agent the existing documents and checks that define correct work in this repository.
3. [Choose the work you need](skills.md): request an investigation, implementation, review, or handoff in ordinary language.

## Follow the part that matters now

| What you need next | Read |
| --- | --- |
| Have one agent investigate the save request while another checks browser reload | [Working with other agents](agents.md) |
| Continue the investigation in a later conversation, or understand what is remembered | [Returning to unfinished work](memory.md) |
| Report a problem in Neurath itself or propose a reusable improvement | [Sharing a Neurath issue](reporting.md) |

If you are changing Neurath itself, begin with [contributor onboarding](../contributing/index.md). That section also contains the command, configuration, and tool references used by agents operating Neurath.
